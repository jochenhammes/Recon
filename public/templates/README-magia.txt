PET templates from the Magia toolbox (Turku PET Centre)

Files: magia_FDG.nii.gz ([18F]FDG, 2 mm), magia_PiB.nii.gz ([11C]PiB, 1 mm), magia_raclopride.nii.gz ([11C]raclopride, 1 mm)
Source: https://github.com/tkkarjal/magia/tree/master/templates (files [18f]fdg.nii, [11c]pib.nii, [11c]raclopride.nii)
Space: MNI152 (SPM), grids as in the source.
Licence: MIT licence of the Magia repository (see LICENSE-magia-MIT.txt), which contains these files.

Please cite:

  Toolbox for PET Neuroinformatics. Front Neuroinform 2020; 14:3. https://doi.org/10.3389/fninf.2020.00003

Modification for Recon Studio: converted to little-endian float32 NIfTI-1 with gzip (NaN set to 0); values unchanged.
